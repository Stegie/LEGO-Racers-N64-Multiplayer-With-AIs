# LEGO-Racers-N64-Multiplayer-With-AIs
LEGO Racers N64 Circuit Editor (IPS): Modifies the original game to support two-player split-screen Circuit Races with AI opponents, preserving the four-race championship format, original scoreboard, and cumulative points system.

LEGO Racers N64 Versus Editor (EXE): A Windows application that lets users select 0–4 AI opponents for two-player split-screen Versus races, automatically patching their N64 ROM with the selected number of computer racers.
